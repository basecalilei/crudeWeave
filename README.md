# crudeWeave by Crudebox

**Open it:** https://GITHUB_USER.github.io/crudeWeave/

Drop in any image and see it as the Jacquard-woven tapestry fabric Crudebox cuts into hoodies. Zoom in for single threads, zoom out for the blanket look, and export the result as an image.

- Everything runs in your browser. Your images are never uploaded anywhere.
- Use desktop Chrome or Edge. It needs WebGL2 and isn't built for phones.
- The first visit can sit on the loading box for several seconds while your graphics card prepares the cloth shader. Later visits start in about a second.

## Using it

1. Drag an image onto the box, or click the box to choose one.
2. Scroll to zoom, drag to pan. **Fit** shows the whole piece.
3. The views along the top (or keys 1–7) show the woven cloth, how it reads from across the room, the design map, and more.
4. The sliders icon (top right) opens the settings: size, colour prep, yarn look and a presentation grade.
5. **Export** saves the woven image at original size, 2× or 4×.
